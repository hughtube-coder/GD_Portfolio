# Equilibrium Dynamics Portfolio

Static portfolio site (HTML, CSS, JS). No build step.

## Publish on GitHub Pages
1. Create a repo (e.g. `portfolio`) and upload everything in this folder (keep `index.html` at the root).
2. Repo Settings > Pages > Source: "Deploy from a branch" > `main` / root > Save.
3. Your site will be live at `https://<username>.github.io/<repo>/` after a minute or two.

## Things to edit
- `about.html`: certifications, GitHub and Facebook links (search for `TO EDIT`).
- Photos: replace `slide-*.jpg` and `tile-*.jpg` with your own pictures (same file names).
- `promo.mp4` is a compressed copy (about 8 MB) of your promo video.
